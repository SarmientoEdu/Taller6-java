1. ¿Qué índice tiene el último elemento de un arreglo de tamaño 5?

RESPUESTA: Tiene índice 4. Los índices empiezan en 0, así que un arreglo de tamaño 5 usa las posiciones 0, 1, 2, 3 y 4.


──────────────────────────────────────────
2. ¿Qué pasa si intentas acceder a notas[5] en este arreglo? ¿Qué error esperas?

RESPUESTA: Se produce un error en tiempo de ejecución: ArrayIndexOutOfBoundsException. El arreglo solo tiene índices válidos de 0 a 4; el compilador no detecta este acceso porque el índice es una expresión que se evalúa al ejecutar.


──────────────────────────────────────────
3. ¿Por qué se inicializa maximo = notas[0] en vez de maximo = 0?

RESPUESTA: Porque el arreglo podría contener solo números negativos o todos menores que 0. Si se inicializara en 0, el máximo calculado sería incorrecto. Usar notas[0] garantiza que la comparación parte de un valor que realmente existe en el arreglo. Lo mismo aplica para el mínimo.


──────────────────────────────────────────
4. ¿Qué significa (double) antes de suma? ¿Qué pasaría si lo quitas?

RESPUESTA: Es un cast que convierte el valor de suma a double antes de hacer la división. Sin el cast, la división sería entera y el promedio se truncaría: por ejemplo, 578 / 8 daría 72 en lugar de 72.25. El cast obliga a que la división sea decimal.
