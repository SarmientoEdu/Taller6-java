1. ¿Qué índice tiene el último elemento de un arreglo de tamaño 5?

RESPUESTA: El índice 4. Como los índices empiezan en 0, el último siempre es el tamaño menos 1 (5 - 1 = 4).


──────────────────────────────────────────
2. ¿Qué pasa si intentas acceder a notas[5] en este arreglo? ¿Qué error esperas?

RESPUESTA: El programa se cae en tiempo de ejecución con un ArrayIndexOutOfBoundsException, porque la posición 5 no existe (solo van de la 0 a la 4). Compila bien, pero falla al momento de correr.


──────────────────────────────────────────
3. ¿Por qué se inicializa maximo = notas[0] en vez de maximo = 0?

RESPUESTA: Porque así se compara contra un valor que de verdad está en el arreglo. Con el máximo y notas positivas funcionaría igual, pero con el mínimo no: si minimo empieza en 0 nunca cambia, porque ninguna nota es menor que 0, y saldría 0 aunque nadie lo haya sacado. Empezar con el primer elemento sirve para cualquier caso.


──────────────────────────────────────────
4. ¿Qué significa (double) antes de suma? ¿Qué pasaría si lo quitas?

RESPUESTA: Es un cast, convierte suma a double antes de dividir para que el resultado tenga decimales. Si se quita, Java hace una división entera (int / int) y se pierden los decimales. Por ejemplo, con las 8 notas de prueba daría 72.00 en vez de 72.25.
